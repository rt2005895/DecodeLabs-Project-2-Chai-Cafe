# Chai & Coffee – Responsive Café Website

## Project Overview
Chai & Coffee is a responsive café website designed for a fictional café located in Gulberg III, Lahore, Pakistan. The website provides information about the café, its menu, facilities, opening hours, and table reservation form.

## Features
- **Responsive Navigation:** Hamburger menu for mobile devices using HTML and CSS without JavaScript.
- **Hero Section:** Introduction to the café with a call-to-action button.
- **Our Menu:** Displays available drinks and food items with their prices.
- **Why Choose Us:** Highlights café facilities and services.
- **Visit Us:** Displays the café location and opening hours.
- **Reservation Form:** Includes fields for name, phone number, date, and number of guests.
- **Responsive Layout:** Adapts to mobile phones, tablets, and desktop screens.
- **Smooth Scrolling:** Provides smooth navigation between website sections.

## Technologies Used
- **HTML5:** Used to create the structure and content of the website.
- **CSS3:** Used for styling, colors, spacing, and layout.
- **CSS Flexbox:** Used for navigation and menu item alignment.
- **CSS Grid:** Used to create responsive page layouts.
- **Media Queries:** Used to adjust the layout for different screen sizes.
- **Google Chrome:** Used for testing and previewing the website.
- **Visual Studio Code:** Used as the code editor.

## Responsive Design
Mobile: Single-column layout.
Small tablets: Two-column feature tiles.
Tablets: Two-column sections and desktop navigation.
Desktop: Four-column feature layout.

## How to Run the Project
1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Make sure `index.html` and `style.css` are in the same folder.
4. Open `index.html` in your web browser.
5. Explore the website on different screen sizes.
